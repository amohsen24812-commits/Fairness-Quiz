⚖️ Fair or Not Fair?
A fun game for kids about fairness. Read each situation and decide: is it FAIR or NOT FAIR?
8 questions about everyday school and home situations
Earn 5 points 💫 for each correct answer
Every answer comes with a short reason
A balance scale that tips toward your answer
Stars at the end and a Play again button
Works on phones and computers (add it to your Home Screen to use it like an app)
Play
Open `index.html` in any browser, or play online on GitHub Pages.
Started as a Code Studio project.
